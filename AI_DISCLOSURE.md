# AI disclosure

This independent community plugin was developed using OpenAI ChatGPT. The user defined the feature requirements, directed the design, and tried the plugin in LearnHarness. ChatGPT generated the implementation, documentation, packaging, and automated checks. A line-by-line human review has not been established.

Testing included real local Pocket TTS synthesis, stock LearnHarness host activation and simulated lesson playback. Word alignment is estimated. The latest settings layout and selection toolbar have not been independently verified in a full desktop end-to-end test.

This is an independent project and is not endorsed by LearnHarness or Kyutai.
